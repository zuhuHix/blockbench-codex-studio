# Security Policy

Please do not open a public issue for suspected vulnerabilities or accidentally exposed secrets.

Use GitHub's private vulnerability reporting for this repository. Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Do not include real access tokens, API keys, private model files, or confidential project assets in reports.

The MCP server is intended to bind only to the loopback interface. Treat any configuration that exposes it to a LAN or the public internet as unsupported and unsafe.
